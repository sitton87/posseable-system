Posseable System – מפת מערכת

מבט על מקצועי שמציג את רצף השלבים: הקמה, תשתיות, שכבת השירותים, API ו-UI. כל חלק מצוין כדי שיהיה ברור מה לבדוק או ללמוד בכל נקודת כניסה.

ארבעת שלבי ההיכרות

הסדר המומלץ לעבודה שיטתית

1. תיעוד והקמה

  • קריאת README / SETUP_GUIDE
  • הגדרת `.env.local` ו-SQL Server
  • הרצת `npm install && npm run dev`

2. תשתיות

  • `lib/`, `db/connection.ts`, `type.ts`
  • שירותי הרשאות, אימייל, סיסמאות
  • Middleware והגנות עמודים

3. API ושירותים

  • Route Handlers תחת `app/api/**`
  • שכבת service וקריאות DB
  • מבנה נתונים והקשר ל-SQL

4. UI ומודולים

  • `app/(main)/layout.tsx` + Navbar
  • קומפוננטים משותפים + hooks
  • מסכי CRUD (equipment, volunteers...)

תרשים על – זרימת בקשה

מהדפדפן ועד למסד הנתונים
flowchart TD A[דפדפן / App Router] --> B[Middleware\nSession validation] B --> C[AccessControl + PagePermissionGate] C --> D[Service Layer\nlib/services/*] D -->|query| E[(SQL Server)] D -->|business data| F[API Routes\napp/api/**] F --> G[UI Components\napp/(main)/*] G --> A

ההרשאות מפוקחות כבר במידלוור ולאחר מכן ברמת העמוד. השירותים מרכזים את הלוגיקה העסקית, ה-API מחזיר JSON קצר וברור, וה-UI מציג נתונים רק לאחר אישור.
